1. PROJECT OBJECTIVE
   ==================================================

The overall objective is to investigate and build a collaborative intrusion-detection framework suitable for financial networks where multiple institutions, branches, or logical network clients can learn from distributed network-flow data without directly centralizing raw traffic data.

The system should study and integrate, where justified:

1. Network intrusion detection.
2. Federated learning.
3. Privacy-preserving machine learning.
4. Continual learning.
5. Robust evaluation under heterogeneous clients.
6. Generalization across domains, clients, time periods, or datasets.

The project must NOT make unsupported claims such as:

* CIC-IDS2017 is a financial-sector dataset.
* Federated learning automatically guarantees privacy.
* Differential privacy protects everything.
* Flow-level features can always perfectly detect SQL injection or XSS.
* LwF is automatically the best continual-learning algorithm.
* FedProx is automatically better than FedAvg.
* deep learning is automatically better than classical ML.
* fewer features automatically mean better generalization.
* higher accuracy automatically means the best model.

All claims must be technically defensible.
