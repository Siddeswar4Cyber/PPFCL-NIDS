# PPFCL-NIDS

Privacy-Preserving Federated Continual Learning Network Intrusion Detection System for Financial Networks.

Current checkpoint: CP4 preprocessing complete. P1 provides five fitted development pipelines and verified model-ready training/validation files, with no transformed merging of admitted S1 groups. See the [preprocessing protocol](docs/CP4-preprocessing-P1.md), [results](reports/CP4-preprocessing-results.md), and [project status](docs/STATUS.md). Next is CP5: the bounded CPU baseline pilot. Model/FL/privacy/CL choices remain provisional, and final-test scores remain sealed.

This is a student research project using a financial-network deployment scenario. CIC-IDS2017 is a general IDS benchmark, not banking telemetry. The user already has the dataset; do not download it or additional datasets without an explicit later request.
